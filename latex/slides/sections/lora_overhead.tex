      \textbf{Inference overhead} (per forward pass):
      \begin{itemize}
        \item Extra FLOPs per projection:
              $d_\mathrm{in}{\cdot}r + r{\cdot}d_\mathrm{out} \ll d_\mathrm{in}{\cdot}d_\mathrm{out}$
        \item Example: \texttt{q\_proj}: $8192{+}8192$ vs.\ $4M$
              \textbf{($<\!0.5\%$ overhead)}
        \item Memory: 2.8M fp32 params $\approx$ \textbf{11 MB}
              vs.\ $\sim$2 GB base model
        \item LoRA correction runs on \emph{digital} hardware
              — does not increase analog area
      \end{itemize}

      \vspace{0.15em}
      \vspace{0.15em}

        \small 0.28\% extra params, $<0.5\%$ extra FLOPs,
        correction entirely in digital post-processing.
        The trade-off is \textbf{strongly favourable}.
