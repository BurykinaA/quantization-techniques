\begin{abstract}
    Analog in-memory and optical matrix--vector accelerators promise substantial energy savings for large language model (LLM) inference, but they introduce an output-side error absent from purely digital deployment. After each analog accumulation, a finite-resolution analog-to-digital converter (ADC) maps the result onto a hardware-fixed lattice, adding a coarse quantization step on top of the usual weight and activation quantization. Crucially, unlike the weight and activation step sizes that calibration is free to tune, this ADC step is a hardware constant fixed by tile width, ADC precision, and range scaling. Standard post-training quantization (PTQ) can thus reshape the values fed into the ADC, but it cannot make the ADC lattice itself any finer. Existing analog-aware methods address this with quantization-aware training or full finetuning, which requires end-to-end gradient training of the entire model with the hardware in the loop and must be repeated for each model and hardware configuration---prohibitively expensive at LLM scale. We instead ask how far a pretrained decoder-only LLM can be adapted to this ADC-constrained path by post-training methods alone.

    We adapt and evaluate Llama-3.2-1B under this ADC-constrained path on WikiText-2 and C4 perplexity and standard downstream benchmarks. A naive PTQ model is unusable---W4A4 WikiText-2 perplexity collapses to $2354.86$---so making it work requires two ingredients. ADC-aware calibration built on FlatQuant (propagated hidden states, a mixed clean/ADC objective, and bounded diagonal scaling under a staged schedule) first brings perplexity down to $26.66$. A rank-4 post-ADC LoRA correction, trained with the analog backbone frozen, then reduces WikiText-2/C4 ADC perplexity to $14.03/23.20$ using only $0.15\%$ extra parameters; the same recipe carries over to a hardware-realistic unsigned shift-subtract readout.

    To our knowledge, this is the first fully post-training pipeline that turns an otherwise-collapsed ADC-constrained LLM into a working model, showing that fixed low-resolution ADCs can be handled by lightweight adaptation on the digital side of the analog--digital boundary rather than by full retraining.
    \end{abstract}
    
    \section{Introduction}
    
    Large language models are dominated by dense linear projections. During autoregressive decoding, each generated token requires repeated reads of large weight matrices, so inference is often limited by memory traffic and data movement rather than raw arithmetic throughput. In-memory computing (IMC) and optical accelerators address this bottleneck by executing matrix--vector multiplication (MVM) directly in the physical substrate that stores the weights. The analog array performs the accumulation, but the next transformer operation still expects a digital tensor.
    
    That readout stage is the central focus of this paper. In a standard digital low-bit model, the dominant approximation error comes from quantizing weights and activations. In an analog deployment path, there is an additional output-side quantizer: after each analog accumulation, a finite-resolution ADC maps the result onto a discrete lattice before the next layer can use it. Formally, if $x_q$ and $W_q$ denote the activation and weight integer codes, the integer accumulation $y_{\mathrm{int}} = W_q x_q$ is mapped as
    \begin{equation}
        y_{\mathrm{adc}} = \Delta \cdot \mathrm{clip}\!\left(\left\lfloor \frac{y_{\mathrm{int}}}{\Delta} \right\rfloor, n_a, p_a\right),
        \label{eq:intro_adc}
    \end{equation}
    where $(n_a,p_a)$ are the output-code bounds and the step size is
    \begin{equation}
        \Delta = \frac{2\,M\,q_x\,q_w}{2^{b_a}\,k},
        \label{eq:intro_delta}
    \end{equation}
    with tile width $M$, ADC bit-width $b_a$, range-scaling factor $k$, and input/weight code ranges $q_x,q_w$. Crucially, $\Delta$ is not a learnable software quantity: every term in Eq.~\eqref{eq:intro_delta} is fixed by hardware. Therefore, even if weights and activations are quantized well, the accumulated output can still be rounded into a coarse lattice, clipped, or driven into a dead zone (Figure~\ref{fig:deadzone}).

\label{fig:deadzone}
\end{figure*}
    
    This failure mode is especially severe for LLMs. Transformer hidden states contain rare but very large activation outliers. Under max-based per-token scaling, a single outlier channel can determine the activation scale and compress typical channels into a narrow band of integer codes. Once those codes are accumulated tile by tile and passed through a coarse ADC lattice, output bins are poorly used and small accumulations collapse to zero. Standard LLM PTQ methods reduce input-side quantization error, but they are not designed to optimize the post-accumulation ADC output.
    
    Recent analog-aware methods such as RAOQ and Analog Foundation Models confirm that analog deployment cannot be solved by digital quantization alone, but they operate in a more training-intensive regime that we discuss in the next section. Our question is narrower: starting from an already trained decoder-only LLM, and assuming full analog-aware finetuning is undesirable or unavailable, how far can post-training adaptation go?
    
    Taken together, these observations define the problem we tackle. The ADC is a fixed, output-side quantizer that PTQ cannot sharpen; its damage accumulates block by block; and the transforms normally used to fight outliers have limited reach. We address all three with a fully post-training recipe that combines ADC-aware calibration \emph{before} the converter with a lightweight digital correction \emph{after} it. This separation between pre-ADC calibration and post-ADC correction is the key conceptual distinction of our method.

    Our contributions follow directly from these problems. \textbf{First}, we formulate Llama-style inference under a tiled ADC-constrained MVM model and isolate ADC-induced error from ordinary quantization error using bypass evaluation and per-layer diagnostics. \textbf{Second}, we develop an ADC-aware PTQ pipeline---propagated calibration, an $\alpha$-mixed objective, and bounded diagonal scaling under a staged schedule---backed by a lemma showing that orthogonal Kronecker transforms have an intrinsic ceiling on outlier suppression, which motivates the diagonal scaling. \textbf{Third}, we introduce a post-ADC rank-4 residual LoRA correction that, with the analog path frozen, reduces WikiText-2/C4 ADC perplexity to $14.03/23.20$ and surpasses our INT8 PTQ baseline. \textbf{Finally}, we show that the same recipe transfers to a hardware-realistic unsigned shift-subtract readout, where per-layer ADC range search and post-ADC correction are complementary.
    
    \section{Background and Related Work}
    
    \subsection{ADC-Constrained Analog Inference}
    
    Analog in-memory and optical accelerators reduce data movement by executing MVM directly in the substrate that stores the weights \cite{xiao2021accuracy,spall2022hybrid,legallo2023mixed}. Weights are mapped to physical states, the input is applied as an analog excitation, and array physics performs the accumulation. Because the result is analog while the next transformer operation expects a digital tensor, each MVM must be followed by an ADC.
    
    This output quantizer differs fundamentally from standard digital quantization. First, it is applied \emph{after} accumulation, when information from many channels has already been mixed. Second, its step size is fixed by hardware parameters, so a software method can improve scale selection but cannot arbitrarily reduce the lattice spacing. As a result, analog output quantization is a distinct source of error rather than a minor implementation detail.
    
    Recent analog-aware methods make this point explicit. RAOQ addresses output quantization through a dedicated training stage after QAT \cite{tang2024raoq}, while Analog Foundation Models adapts pretrained LLMs to noisy low-precision analog hardware using a broader hardware-aware training pipeline \cite{buchel2025analog}. We build on the same diagnosis---that ADC/output quantization is a first-class bottleneck---but pursue a lighter-weight regime based on post-training calibration and a small digital correction module.
    
    \subsection{Low-Bit LLM Quantization}
    
    Quantization maps real-valued tensors to low-bit integer codes to reduce memory, bandwidth, and arithmetic cost \cite{gholami2021survey,jacob2018quantization}. In symmetric uniform quantization, values are scaled, rounded, clipped, and dequantized back to floating point. PTQ calibrates these operations on a small dataset; QAT places quantization inside the optimization loop and typically relies on the straight-through estimator for non-differentiable rounding \cite{esser2019learned}.
    
    LLMs are particularly difficult to quantize because their hidden states are anisotropic and outlier-heavy. SmoothQuant migrates dynamic range from activations into weights through an equivalent diagonal transform \cite{xiao2022smoothquant}. Outlier Suppression+ uses channel-wise shifting and scaling \cite{wei2023outlier}. AWQ protects salient weights selected from activation statistics \cite{lin2023awq}, OmniQuant combines learnable clipping with equivalent transformations for very low-bit PTQ \cite{shao2023omniquant}, and GPTQ frames weight quantization as a second-order reconstruction problem \cite{frantar2022gptq}. Rotation-based methods such as QuaRot and SpinQuant suppress residual-stream outliers with fixed or learned rotations \cite{ashkboos2024quarot,liu2024spinquant}, while FlatQuant learns invertible per-projection Kronecker transforms and folds them into the weights \cite{liu2024flatquant}. CBQ and quantization-error-propagation PTQ move beyond local block reconstruction by modeling how quantization error accumulates across depth \cite{ding2023cbq,qep2025}. These methods improve digital quantization, but they do not directly optimize the separate ADC output lattice.
    
    \subsection{Lightweight Post-Quantization Adaptation}
    
    When pure PTQ saturates, a natural next step is to freeze the quantized backbone and attach a small trainable correction. Prior work on low-bit transformers has shown that aggressive quantization often benefits from finetuning or QAT-style recovery \cite{liu2023llmqat,chen2024efficientqat}. Low-rank methods such as LoRA and related quantization-error reconstruction schemes capture much of the residual error with only a small number of trainable parameters \cite{hu2022lora,zhang2024lqer}.
    
    For ADC-constrained inference, this family of methods is particularly attractive. A frozen quantized analog path can preserve the hardware mapping, while a lightweight digital residual branch learns the remaining distortion. What is non-standard in our setting is the placement of the correction: not before quantization, but \emph{after} the ADC, on the digital side of the analog--digital boundary. In short, prior work reduces input-side error effectively but leaves the output-side ADC lattice largely unaddressed, and existing analog-aware remedies rely on hardware-aware training; we instead ask how much of that residual loss post-training adaptation alone can remove.

We consider a pretrained decoder-only transformer whose linear projections are executed on a tiled ADC-constrained MVM accelerator. For each projection $y = xW^\top$, activations are quantized per token and weights per output channel. The integer accumulation is computed tile-by-tile, quantized by the fixed ADC of Eq.~\eqref{eq:intro_adc}, and dequantized by the activation and weight scales (Figure~\ref{fig:optical}). The effective layer map is
\begin{equation}
    \hat{f}^{\mathrm{ADC}}_\ell(x) = D_{\mathrm{out}}\,Q_{\mathrm{ADC}}\!\left(Q_w(W_\ell)\,Q_x(x)\right).
    \label{eq:adc_layer}
\end{equation}
Here $Q_x$ and $Q_w$ are the input-side quantizers, $Q_{\mathrm{ADC}}$ is the fixed output lattice of Eq.~\eqref{eq:intro_adc}, and $D_{\mathrm{out}}$ absorbs the activation and weight scales. Our goal is to preserve model quality under this constraint without retraining the full model. This raises a natural progression of questions: how far transform-based PTQ can mitigate the ADC, whether reconstruction-only calibration is sufficient or an ADC-aware objective is required, and when adaptation beyond PTQ becomes necessary---which the rest of the paper answers in turn. The study uses a software ADC simulator that models finite-resolution output quantization, tiling, and integer arithmetic while abstracting device-level non-idealities.

\section{ADC-Aware Post-Training Adaptation}

We build the method in four PTQ steps---a FlatQuant baseline, ADC-propagated calibration with a mixed objective, bounded diagonal scaling, and a staged schedule---and then add a post-ADC residual branch for the error PTQ provably cannot reach.

\subsection{Baseline: FlatQuant for Llama}

FlatQuant exploits a simple linear invariance of the MVM. For any invertible $T$,
\begin{equation}
    y = xW^{\top} = (xT^{-1})(TW^{\top}),
    \label{eq:flatquant}
\end{equation}
so choosing $T$ to flatten the distribution of $xT^{-1}$ improves both integer quantization and ADC bin coverage while preserving the map. A full $d\times d$ transform is prohibitive, so FlatQuant parameterizes $T = T_1 \otimes T_2$, reducing the number of trainable parameters from $\mathcal{O}(d^2)$ to $\mathcal{O}(d)$ \cite{liu2024flatquant}.

Calibration is teacher--student. A frozen FP teacher produces $y^\star$, and the quantized student minimizes $\|\hat{y} - y^\star\|_2^2$ over the Kronecker factors; after calibration, $T$ is folded into the weights at no inference cost. We wrap all seven projections of each decoder block ($q,k,v,o$ in grouped-query attention and \texttt{gate}, \texttt{up}, \texttt{down} in the SwiGLU FFN). Standard block calibration uses clean teacher activations,
\begin{equation}
    \mathcal{L}_{\mathrm{FP}} = \left\| \hat{B}(x^{\star}) - B_{\mathrm{FP}}(x^{\star}) \right\|_2^2,
    \label{eq:lfp}
\end{equation}
which is well matched to digital PTQ but mismatched to analog deployment, where each block receives activations already corrupted by prior ADC readouts.

\subsection{Cross-Block Propagation and $\alpha$-Mixing}

To match deployment, blocks are calibrated sequentially from layer $0$ to $L-1$. When calibrating block $\ell$, its input is the ADC-quantized output of the already calibrated block $\ell-1$. Thus the block sees the same accumulated distortion during calibration that it will see at inference:
\begin{equation}
    \mathcal{L}_{\mathrm{ADC}} = \left\| \hat{B}(\hat{x}) - B_{\mathrm{FP}}(x^{\star}) \right\|_2^2,
    \label{eq:ladc}
\end{equation}
where $\hat{x}$ is the ADC-propagated hidden state. Full propagation is noisy in W4A4 because gradients must pass through several floor operators via STE. We therefore interpolate between the clean and propagated objectives,
\begin{equation}
    \mathcal{L}(\alpha) = (1-\alpha)\,\mathcal{L}_{\mathrm{FP}} + \alpha\,\mathcal{L}_{\mathrm{ADC}}.
    \label{eq:alpha}
\end{equation}
The clean term stabilizes the transform, while the propagated term teaches robustness to ADC distortion. A sweep in the appendix shows that $\alpha = 0.5$ is the best W4A4 point: below it the ADC regime is under-weighted, above it floor-induced gradient noise degrades transform quality. At INT8, propagation alone drops ADC perplexity from $28.86$ to $14.55$ with no extra parameters.

\subsection{Trainable Per-Channel Diagonals}

Propagation and $\alpha$-mixing fix \emph{what} the calibration optimizes, but the transform itself still has limited capacity to tame outliers: rotations redistribute energy across channels without rescaling any of them. We first make this precise.

\begin{lemma}[Rotation-only outlier suppression bound]
\label{lem:rotation}
Let $P = L \otimes R$ with $L^\top L = I$, $R^\top R = I$ be an orthogonal Kronecker transform on $\mathbb{R}^d$, and define the effective participation ratio $m_{\mathrm{eff}}(x) = \|x\|_2^2 / \|x\|_\infty^2 \in [1, d]$. Then for every such $P$,
\begin{equation}
    \|xP\|_\infty \;\ge\; \frac{\|x\|_2}{\sqrt{d}},\qquad
    \frac{\|x\|_\infty}{\min_{P}\|xP\|_\infty} \;\le\; \sqrt{\frac{d}{m_{\mathrm{eff}}(x)}} .
\end{equation}
\end{lemma}

The proof (appendix) follows from orthogonal invariance of $\|\cdot\|_2$ and the $\ell^\infty$--$\ell^2$ inequality. With $d = 2048$ and $8$ dominant channels ($m_{\mathrm{eff}} \approx 8$), the peak can be suppressed by at most a factor $16$. If more suppression is required, rotation alone is provably insufficient. Moreover, the Kronecker family is a strict low-dimensional subset of all orthogonal transforms ($2512$ vs.\ $\approx 2.1\times10^6$ free parameters for $d=2048$), so the true reachable suppression can be even smaller.

We therefore absorb a trainable diagonal $D = \mathrm{diag}(d_1,\ldots,d_c)$, $d_i \in [10^{-4}, 10]$, into the transform, preserving the map by equal-and-opposite rescaling of the weights,
\begin{equation}
    y = (x\,D^{-1}T^{-1})(T\,D\,W^{\top}).
    \label{eq:diag}
\end{equation}
Because $D$ is not orthogonal, it breaks the $\ell^2$-energy invariance of Lemma~\ref{lem:rotation}. Setting $d_j < 1$ reduces the contribution of an outlier channel \emph{before} the per-token scale is computed, achieving suppression no rotation can match. The bounds prevent degenerate scaling, and $D$ folds into the weights at deployment. We place separate diagonals on the attention path (around $q/k/v$ and $o$) and the MLP path (around \texttt{gate}/\texttt{up} and \texttt{down}). Ablations show that they play different roles: MLP diagonals drive no-ADC transform quality, while attention diagonals close the ADC gap.

\subsection{Staged Calibration}

With the objective and the transform family in place, the last question is how to optimize them together. Training all Kronecker factors and both diagonals jointly with $\alpha = 0.5$ is unstable: attention gradients dominate before MLP transforms converge. We therefore split calibration into two stages. \emph{Stage~A} trains the MLP Kronecker factors and MLP diagonals with clean reconstruction ($\alpha = 0$), giving a stable warm start. \emph{Stage~B} freezes the MLP diagonals, unfreezes the attention Kronecker factors and attention diagonals, and fine-tunes with $\mathcal{L}(0.5)$ at a lower learning rate. This schedule avoids gradient interference and gives the best pure-PTQ checkpoint (bypass $18.50$, ADC $27.60$).

Algorithm~\ref{alg:calibration} makes the procedure precise over the projection set $\mathcal{P}=\{q,k,v,o\}\cup\{\texttt{gate},\texttt{up},\texttt{down}\}$, with $\mathrm{attn}=\{q,k,v,o\}$ and $\mathrm{MLP}=\{\texttt{gate},\texttt{up},\texttt{down}\}$. Gradients through the quantizers $Q_x,Q_w,Q_{\mathrm{ADC}}$ use the straight-through estimator (STE).

\begin{algorithm}[tb]
\caption{ADC-Aware Staged PTQ Calibration}
\label{alg:calibration}
\textbf{Input}: FP model $F$ with teacher blocks $\{B^{\mathrm{FP}}_\ell\}_{\ell=1}^{L}$; calibration set $C$; hardware $H=(M,b_a,k,q_x,q_w)$ fixing the ADC step $\Delta$; base lr $\eta$; epochs $E_A,E_B$; box $[\underline{d},\overline{d}]=[10^{-4},10]$\\
\textbf{Output}: Quantized ADC-aware model $\hat{F}_{\mathrm{ADC}}$
\begin{algorithmic}[1]
\STATE \textbf{Def.} $\tilde{T}_p:=T_pD_p$; per projection $p$,\\
\quad $\hat{f}_p(x)=D_{\mathrm{out}}Q_{\mathrm{ADC}}\!\big(Q_w(\tilde{T}_pW_p^\top)\,Q_x(x\tilde{T}_p^{-1})\big)$; \\
\quad $\hat{B}_\ell(\cdot;\theta)$ composes $\{\hat{f}_p\}$ over $p\in\mathcal{P}$
\FOR{block $\ell = 1$ to $L$}
\STATE $x^{\star}\!\gets$ clean input; \ $y^{\star}\!\gets B^{\mathrm{FP}}_\ell(x^{\star})$ \hfill(teacher)
\STATE $\hat{x}\gets$ ADC-propagated output of calibrated block $\ell{-}1$
\STATE init $T_p=T_{p,1}\!\otimes T_{p,2}$, $D_p=I$, $\forall p\in\mathcal{P}$
\STATE \textbf{Stage A} ($\alpha{=}0$): $\theta_A=\{T_p\}_{p\in\mathrm{MLP}}\!\cup\{D^{(m)}\}$
\FOR{$e=1$ to $E_A$; minibatch $\subset C$}
\STATE $\mathcal{L}_{\mathrm{FP}}=\|\hat{B}_\ell(x^{\star};\theta)-y^{\star}\|_2^2$ \hfill(Eq.~\ref{eq:lfp})
\STATE $\theta_A\gets\mathrm{AdamW}(\theta_A,\nabla_{\theta_A}\mathcal{L}_{\mathrm{FP}};\eta)$ \hfill(STE)
\STATE $D^{(m)}\gets\mathrm{clip}(D^{(m)},\underline{d},\overline{d})$
\ENDFOR
\STATE freeze $D^{(m)}$; \ $\mathrm{lr}\gets 0.1\,\eta$
\STATE \textbf{Stage B} ($\alpha{=}0.5$): $\theta_B=\{T_p\}_{p\in\mathrm{attn}}\!\cup\{D^{(a)}\}$
\FOR{$e=1$ to $E_B$; minibatch $\subset C$}
\STATE $\mathcal{L}_{\mathrm{ADC}}=\|\hat{B}_\ell(\hat{x};\theta)-y^{\star}\|_2^2$ \hfill(Eq.~\ref{eq:ladc})
\STATE $\mathcal{L}(0.5)=\tfrac12\mathcal{L}_{\mathrm{FP}}+\tfrac12\mathcal{L}_{\mathrm{ADC}}$ \hfill(Eq.~\ref{eq:alpha})
\STATE $\theta_B\gets\mathrm{AdamW}(\theta_B,\nabla_{\theta_B}\mathcal{L}(0.5);0.1\eta)$
\STATE $D^{(a)}\gets\mathrm{clip}(D^{(a)},\underline{d},\overline{d})$
\ENDFOR
\STATE fold $W_p^\top\!\gets\tilde{T}_pW_p^\top$, fuse $\tilde{T}_p^{-1}$ into input side; store $Q_w(\cdot)$, fixed $\Delta$ \hfill(Eq.~\ref{eq:diag})
\ENDFOR
\RETURN $\hat{F}_{\mathrm{ADC}}$
\end{algorithmic}
\end{algorithm}

Even the best staged checkpoint still leaves an ADC gap, and this ceiling is fundamental: pure PTQ can only reshape the signal \emph{before} the ADC. Once the ADC maps a continuous accumulation to a discrete code, all sub-step information inside that bin is gone from the frozen analog path. This is why pure PTQ plateaus around $27.5$--$28.5$ W4A4 ADC perplexity across calibration strategies. We add a small digital residual branch \emph{after} the ADC (Figure~\ref{fig:lora}). For a projection with frozen ADC output, the adapted output is
\begin{equation}
    y = \mathrm{ADC}_{\mathrm{frozen}}(\hat{x}) + \frac{s}{r}\,B\!\left(A\,x_{\mathrm{fp}}\right),
    \label{eq:lora}
\end{equation}
with $A \in \mathbb{R}^{r\times d}$, $B \in \mathbb{R}^{d_{\mathrm{out}}\times r}$, rank $r = 4$, and LoRA scale $s = 8$, all computed in float32 (we reserve $\alpha$ for the calibration mixing coefficient). The entire base---weights, Kronecker factors, diagonals, and ADC steps---stays frozen. Rank-4 adapters on all seven projections of $16$ blocks add $\sim$1.8M parameters ($0.15\%$ of the model). The adapters are trained with next-token cross-entropy plus teacher distillation,
\begin{equation}
    \mathcal{L}_{\mathrm{LoRA}} = \mathrm{CE}(\hat{p}, y) + \lambda\,\mathrm{KL}\!\left(\hat{p}_T \,\|\, p_{\mathrm{FP},T}\right),
    \label{eq:lora_loss}
\end{equation}
with $\lambda = 0.5$ and temperature $T = 2$. Post-ADC placement is essential. A pre-ADC adapter is itself quantized by the fixed lattice, cannot express sub-$\Delta$ corrections, and diverges (ADC perplexity $\approx 105.6$). Post-ADC, the correction is added in the digital domain at full precision with clean gradients, dropping W4A4 ADC perplexity from $27.60$ to $14.03$.

\section{Experiments}

\subsection{Setup}

Experiments use Llama-3.2-1B in bfloat16 \cite{dubey2024llama}: $16$ decoder layers, hidden dimension $2048$, grouped-query attention, and a SwiGLU FFN with intermediate dimension $8192$. The model is small enough to sweep dozens of configurations overnight on a single GPU while remaining representative of the Llama family.

Calibration and LoRA use WikiText-2 training text \cite{merity2017pointer}. We evaluate WikiText-2 and C4 perplexity \cite{raffel2020exploring} with context length $2048$ and stride $1024$, and downstream accuracy via the lm-evaluation-harness \cite{gao2024lmeval}. The main hardware setting uses tile size $M = 256$, ADC bitwidth $b_a = 8$, scaling factor $k = 16$, and W4A4 or W8A8 precision. This gives a signed step $\Delta \approx 2016$ for W8A8 and $\Delta \approx 6.12$ for W4A4.

We report two perplexities. \emph{Bypass} disables the ADC and isolates tiling plus integer quantization. \emph{ADC} enables the full pipeline and is the primary metric; the gap between the two measures ADC-induced degradation. Internal diagnostics (dead-rate, clip-rate, bin usage, reconstruction error) are defined in the appendix. FlatQuant transforms train for $30$ epochs at $5\times10^{-3}$ (Stage~B: $10$ epochs at $5\times10^{-4}$); post-ADC LoRA trains for $5$ epochs at $10^{-4}$.

\subsection{Main Results}

Table~\ref{tab:main} reports the main results. Digital INT8 is nearly lossless, but enabling the ADC sharply degrades quality. The effect is stronger at INT4: the digital baseline is still usable, while the ADC-enabled model remains far worse even after ADC-aware PTQ. Without ADC-aware calibration, the naive W4A4 ADC baseline collapses to $2354.86$ WikiText-2 perplexity; ADC-aware PTQ reduces this to $26.66$ (a factor of $\approx 88$), but still remains far from the bfloat16 baseline of $8.68$.

Post-ADC LoRA closes much of this remaining gap. It reduces WikiText-2/C4 ADC perplexity from $26.66/45.62$ to $14.03/23.20$, closing roughly $70\%$ of the remaining WikiText-2 gap and $69\%$ of the C4 gap, and surpassing INT8 PTQ ($16.85$). Downstream accuracy improves from $41.99$ to $47.07$. The largest gains appear on commonsense and science tasks (HellaSwag, ARC-Easy, PIQA, OpenBookQA), while MMLU and WinoGrande improve less. This suggests that next-token CE+KL transfers well to perplexity, but only partially to all multiple-choice tasks. Per-task numbers are in the appendix.

\subsection{Ablation Summary}

We summarize the key findings here; full tables are in Appendices~C--D. At INT8, propagation is the dominant lever (ADC $28.86 \to 14.55$), while a bin-center auxiliary loss adds only $0.14$. At INT4, full propagation is too noisy and $\alpha = 0.5$ is best. Sample count is also important: the naive $\times 153$ bypass--ADC gap at $128$ samples closes to $\times 1.2$ at $512$ samples with propagation.

Diagonal placement matters. MLP-only scaling gives strong bypass quality but a wide ADC gap; attention-only scaling helps the ADC gap but hurts bypass; staged MLP-then-attention training is best overall (bypass $18.50$, ADC $27.60$). Within the MLP, the \texttt{down} diagonal drives nearly all of the improvement. Stochastic propagation (Bernoulli, Beta) does not beat deterministic $\alpha=0.5$.

For post-ADC LoRA, rank saturates at $r=4$. CE+KL beats CE-only, especially when covering all seven projections (by $2.65$ perplexity) and for C4 transfer (C4 ADC $46.40 \to 23.30$ despite WikiText-2-only training). Covering all $16$ layers beats last-$8$ ($15.63$ vs.\ $20.08$), confirming that ADC error accumulates with depth.

\subsection{Unsigned Shift-Subtract Readout}

The signed readout is a useful reference, but many physical crossbars accept only non-negative currents. We therefore evaluate an unsigned shift-subtract readout. Signed INT4 codes are shifted to $[0,15]$, a single non-negative MVM is performed, and deterministic zero-point terms are subtracted digitally after ADC readout (exact recovery; derivation in the appendix). The unsigned step at global $k = 16$ is
\begin{equation}
    \Delta_u = \frac{M(2^{b_x}-1)(2^{b_w}-1)}{2^{b_a}k} \approx 14.06,
    \label{eq:delta_u}
\end{equation}
more than twice the signed W4A4 step. Because this coarser step imposes a heavier resolution penalty, we add a per-layer search over $k \in \{4,8,16,32,64\}$. For each projection, the search selects the smallest $k$ that avoids ADC saturation on the calibration set, and it runs in place on the frozen PTQ checkpoint.

Table~\ref{tab:unsigned} shows that the global unsigned baseline ($39.00$) is much worse than the signed reference. Per-layer $k$ search alone reduces it to $21.64$ without retraining; post-ADC LoRA reaches $17.29$; and the combination reaches $14.56$. Thus range adaptation before deployment and residual correction after the ADC are complementary, and both transfer to the more realistic unsigned readout.

\section{Discussion}

Three conclusions follow. First, ADC error is not the same as digital quantization error. A no-ADC evaluation can make a low-bit LLM appear healthy while hiding a major hardware-induced degradation, so the ADC must be evaluated inside the inference loop.

Second, ADC-aware calibration is mainly a distribution-matching problem. Clean teacher activations do not match what deeper blocks see at analog deployment time. Propagating ADC-quantized states exposes blocks to their real inference distribution, but the objective must be mixed with a clean term to avoid optimizing only noisy floor-induced gradients.

Third, pure PTQ has a natural ceiling because it acts before the lossy ADC. Transforms, rotations, and diagonals can place the pre-ADC signal in a better range, but they cannot recover sub-step information once the output code is selected. A post-ADC residual branch works precisely because it operates on the digital side of the boundary, making it qualitatively different from another pre-ADC transform. The results also suggest a hardware--software co-design direction: tile size, ADC bitwidth, scaling factor, signedness, and calibration objective jointly determine accuracy, and modest configurability such as per-layer $k$ is valuable when exposed to the calibration pipeline.

\section{Limitations}

This study uses a software ADC simulator rather than measurements on fabricated hardware. Real devices may add non-uniform bins, offset, drift, thermal noise, IR drop, and latency constraints; the simulator isolates finite-resolution output quantization but does not replace hardware validation. The experiments focus on Llama-3.2-1B, and larger models may show different outlier statistics or require different calibration budgets. The adaptation data is WikiText-2, with C4 as transfer evidence, so broader domains should be evaluated. Finally, the post-ADC LoRA branch has nonzero digital overhead and requires access to the adapter input; a hardware implementation must decide whether it runs on a digital co-processor, is restricted to selected projections, or is fused into a larger post-processing path.

\section{Conclusion}

Finite-resolution ADCs introduce an output-side quantization bottleneck that standard digital PTQ does not solve. For Llama-3.2-1B under W4A4 analog inference, naive ADC-enabled FlatQuant collapses, while ADC-aware PTQ with propagated calibration, mixed objectives, bounded diagonals, and staged training restores usable quality. The remaining gap is not removable by pre-ADC calibration alone: a rank-4 digital correction placed after the ADC recovers most of it while keeping the quantized backbone frozen, and the same recipe transfers to a hardware-realistic unsigned readout. The broader message is that the analog--digital boundary is an algorithmic object --- accurate analog LLM inference requires treating the ADC as part of the quantization pipeline, not as a passive hardware detail.

\section{B. Proof of Lemma~\ref{lem:rotation}}

\begin{proof}
Since $P = L \otimes R$ with $L, R$ orthogonal, $P$ is orthogonal, hence $\|xP\|_2 = \|x\|_2$. For any $y \in \mathbb{R}^d$ the standard $\ell^\infty$--$\ell^2$ inequality gives $\|y\|_\infty \ge \|y\|_2/\sqrt{d}$. Applying this to $y = xP$ yields $\|xP\|_\infty \ge \|x\|_2/\sqrt{d}$, the first inequality. Writing $\|x\|_\infty = \|x\|_2/\sqrt{m_{\mathrm{eff}}(x)}$ and dividing by the lower bound gives
\[
    \frac{\|x\|_\infty}{\min_P \|xP\|_\infty} \le \frac{\|x\|_2/\sqrt{m_{\mathrm{eff}}(x)}}{\|x\|_2/\sqrt{d}} = \sqrt{\frac{d}{m_{\mathrm{eff}}(x)}} . \qedhere
\]
\end{proof}

\begin{corollary}[Kronecker capacity]
\label{cor:capacity}
A full orthogonal matrix on $\mathbb{R}^d$ has $d(d-1)/2$ free parameters, whereas $L \otimes R$ has only $a(a-1)/2 + b(b-1)/2$ for $d = ab$. For $d = 2048 = 32 \times 64$ this is $2512$ vs.\ $\approx 2.1 \times 10^6$. Thus the Kronecker family is a strict low-dimensional subset of all orthogonal transforms and may not attain the bound in Lemma~\ref{lem:rotation}; the achievable suppression can be strictly smaller.
\end{corollary}

\section{E. Unsigned (Unipolar) ADC}

Physical crossbars often accept only non-negative currents. Signed INT4 codes $\hat{x},\hat{w}\in[-8,7]$ are shifted by the zero-point $z = 8$ to $\hat{x}^u,\hat{w}^u\in[0,15]$. The crossbar computes one non-negative product $y^u = \langle \hat{x}^u, \hat{w}^u\rangle \in [0, M\cdot 15^2]$, and the ADC floors it with $\Delta_u$ from Eq.~\eqref{eq:delta_u}. The signed inner product is recovered exactly by expanding $\hat{x}^u\hat{w}^u = \hat{x}\hat{w} + 8\hat{w} + 8\hat{x} + 64$:
\begin{equation}
    y_{\mathrm{int}} = \hat{y}^u - 8\!\sum_j \hat{w}^u_j - 8\!\sum_i \hat{x}^u_i + 64M,
\end{equation}
where $\sum_j \hat{w}^u_j$ is precomputed at weight-load and $\sum_i \hat{x}^u_i$ once per token, adding negligible digital overhead. The per-layer $k$ search selects, for each layer $\ell$,
\begin{equation}
    k^*_\ell = \min\!\Big\{ k \in \mathcal{K} : k \ge \frac{M(2^{b_x}-1)(2^{b_w}-1)}{2\,R_\ell} \Big\},
\end{equation}
with $R_\ell = \mathrm{quantile}_{0.999}(|y^u_\ell|)$ and $\mathcal{K} = \{4,8,16,32,64\}$, run in place on the frozen PTQ checkpoint. FlatQuant is retrained with $\Delta_u$ so the transforms are matched to the unipolar step; all other settings carry over from the best bipolar configuration.

The final series was reached through three prior hardware iterations, documented in Table~\ref{tab:readout_evolution}. A four-quadrant unipolar decomposition achieves a finer branch step ($\approx 3.06$) at $4\times$ the ADC reads; a single-read shift-subtract readout is cheaper but harder to calibrate; and an intermediate mismatched setup (transforms trained for the bipolar $\Delta$ evaluated on the unsigned model) exploded to $\sim$94k perplexity, which motivated retraining with $\Delta_u$. Table~\ref{tab:unipolar} reports the final results. Notably, \texttt{best\_ptq\_k\_recal} is worse than \texttt{best\_ptq\_k}: retraining FlatQuant on fixed per-layer $k$ over-specializes the transforms, so in-place $k$ search after global-$k$ training is preferable.

\section{G. Implementation Sketches and Reproducibility}

The listings below are simplified for readability and do not replace the full training code.

\begin{listing}[tb]
\caption{Tiled ADC forward pass.}
\label{lst:adc_forward}
\begin{lstlisting}[language=Python]
def adc_tile_forward(x, weight, bias, delta, qx, qw, na, pa):
    sx = x.abs().amax(-1, keepdim=True).clamp(min=1e-6) / qx
    x_code = round_ste(x / sx).clamp(-qx, qx)
    sw = weight.abs().amax(1).clamp(min=1e-6) / qw
    w_code = round_ste(weight / sw[:, None]).clamp(-qw, qw)
    y_int = linear(x_code, w_code)
    y_adc = floor_ste(y_int / delta).clamp(na, pa) * delta
    y = y_adc * sx * sw[None, :]
    return y if bias is None else y + bias
\end{lstlisting}
\end{listing}

\begin{listing}[tb]
\caption{Block-level mixed calibration loss.}
\label{lst:mixed_loss}
\begin{lstlisting}[language=Python]
def mixed_block_loss(block_q, x_clean, x_adc, y_teacher, alpha):
    loss_clean = mse(block_q(x_clean), y_teacher)
    loss_adc = mse(block_q(x_adc), y_teacher)
    return (1.0 - alpha) * loss_clean + alpha * loss_adc
\end{lstlisting}
\end{listing}

\begin{listing}[tb]
\caption{Post-ADC residual LoRA wrapper.}
\label{lst:lora}
\begin{lstlisting}[language=Python]
class PostADCLoRA(Module):
    def __init__(self, frozen_adc_layer, in_dim, out_dim, rank=4, alpha=8):
        self.base = frozen_adc_layer
        freeze(self.base)
        self.A = Linear(in_dim, rank, bias=False, dtype=float32)
        self.B = Linear(rank, out_dim, bias=False, dtype=float32)
        init_kaiming(self.A.weight); init_zeros(self.B.weight)
        self.scale = alpha / rank

    def forward(self, x):
        y_base = self.base(x)
        y_res = self.B(self.A(x.float())) * self.scale
        return y_base + y_res.to(y_base.dtype)
\end{lstlisting}
\end{listing}

\paragraph{Reproducibility notes.}
All perplexities use sliding-window evaluation with context length $2048$ and stride $1024$. The default signed hardware configuration uses tile size $256$, ADC bitwidth $8$, scaling factor $16$, and W4A4 or W8A8 quantization. The main W4A4 PTQ checkpoint uses $1024$ WikiText-2 calibration samples with staged diagonal training and $\alpha = 0.5$. Post-ADC LoRA is trained for $5$ epochs at learning rate $10^{-4}$, rank $4$, LoRA scale $8$, CE+KL loss, KL weight $0.5$, and distillation temperature $2.0$.
